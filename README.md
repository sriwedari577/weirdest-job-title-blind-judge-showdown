An entry for the Make.fun competition
[Weirdest Job Title: Blind Judge Showdown](https://make.fun/c/u-rusdyxbt-weirdest-job-title-blind-judge-showdown-552d7922):
one weird job title — a hired chief mourner who grieves at strangers' goldfish funerals.

## What it does

Running the program writes one job title to `/output/entry.txt`
(or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set).
The title pairs a real hired role, a chief mourner, with the smallest,
most bathos-laden clientele imaginable: strangers' goldfish.

## Run it

```sh
node main.ts
```

Node 22 or later, standard library only. The output is identical on
every run: no clock, no randomness, no network.
